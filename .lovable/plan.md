## Goal

Make every post detail page (Stream + Scream) look and feel the same: in‑depth review body, a one‑line **Vibe**, **Where to watch**, and **Your next binge…** with 2–3 picks that link to other posts on the site.

## Why this is needed

Inspecting the data shows two problems on Stream posts:
- About half have a long review but no `next_binge` / `favourite_episode`.
- The other half have 3 binge picks but only a ~270‑char body and no JustWatch link.
- No posts have a "vibe" field — it doesn't exist yet.
- "Your next binge" titles are plain text today; only matches by title get auto‑linked.

So a Stream visitor sees either a review OR recommendations, never both, and the section is inconsistent with Scream.

## Plan

### 1. Schema: add `vibe`
Add a new `vibe text` column to `posts` (nullable, max ~140 chars enforced in the Zod validator). One migration.

### 2. Post detail page (`src/routes/post.$slug.tsx`)
- Render a new **The Vibe** block (eyebrow + one‑line tagline) above the review body when `post.vibe` is set — for both sections.
- Show the **Where to watch** button on Stream posts even when `justwatch_slug` is missing? No — keep current behavior (only render when a slug exists), but the backfill below will ensure every Stream post has one.
- "Your next binge" already auto‑links matches via `getPostsByTitles`; keep as is.

### 3. Admin editor
- Add a `vibe` input to `_authenticated/admin.$id.edit.tsx`, `admin.new.tsx`, and to `upsertPost` in `src/lib/posts.functions.ts`.

### 4. Backfill all Stream posts with Lovable AI
A one‑off script (`/tmp/backfill_stream.py`) using the bundled `ai-gateway` skill + `google/gemini-2.5-flash`:

For every published `section='tv'` post, generate any missing fields and write via `supabase--insert`:
- `vibe` — single sentence, ≤120 chars, present‑tense tagline.
- `body` — if shorter than ~900 chars, regenerate an in‑depth review (700–1200 words equivalent of structured HTML matching existing PostBody formatting).
- `justwatch_slug` / `justwatch_type` / `justwatch_country` — derive from title if missing (model proposes slug; defaults `tv-show` / `us`). I'll log proposals for sanity, then insert.
- `next_binge` — if empty, pick 3 titles **from the existing list of published Stream post titles** (passed into the prompt) that thematically match. This guarantees every recommendation links to a real story.
- `favourite_episode` — fill if empty (Stream only).

Scream posts are left alone except for adding `vibe` (also AI‑generated) so the new field renders everywhere.

### 5. Verify
- Open `/post/lioness` and `/post/dahmer` in preview to confirm Vibe renders, Stream now has Where‑to‑watch + binge links, and binge items are clickable.
